# 交友宇宙液态玻璃改造设计

## [S1] 目标与范围

将首页内的“交友宇宙”Tab 改造成与主页一致的真实液态玻璃体验，同时采用 miuix demo 的大标题尺寸和随滚动收缩动画。

本次保留现有 Java `FriendRequestListFragment`、RecyclerView、分页、下拉刷新、卡片、详情、编辑、删除和举报流程。只改造页面顶部结构、搜索交互、发布入口和列表安全区，不迁移整页 Compose，也不修改交友 API。

## [S2] 页面结构

`HomeFragment` 继续提供共享的 `BackdropCaptureFrameLayout` 和底部液态导航。交友 Tab 可见时，在现有 `toolbarHost` 中挂载交友专用 Compose 液态顶栏；主页 Tab 可见时仍挂载现有 `HomeLiquidToolbarController`。

交友页面内容保持在捕获层内。RecyclerView 使用 `clipToPadding=false` 和顶部可滚动留白，初始内容避开大标题，向上滚动后卡片进入透明顶栏后方并成为真实 backdrop。防诈骗提示作为列表顶部内容一起滚动，不固定占用顶栏下方空间。

## [S3] 大标题与滚动动画

顶部左侧显示“交友宇宙”。展开态使用 miuix `TopAppBar` demo 对应的大标题视觉比例；RecyclerView 上滑时，根据实际滚动距离连续插值标题字号、位置和透明度，收缩为状态栏下方的小标题。

标题动画必须连续响应拖动与 fling，不在滚动结束后跳变。下拉回到顶部时恢复大标题。刷新、分页和页面重显不能错误重置当前滚动对应的标题状态。

## [S4] 液态操作区

右侧显示搜索和发布两个独立圆形液态玻璃按钮。玻璃使用与主页顶部相同的真实 View bitmap backdrop、lens、vibrancy、动态高光和轮廓，不使用纯色半透明 Drawable 模拟。

发布按钮打开既有 `FriendRequestCreateFragment`。原右下角 FAB 在液态模式隐藏，避免重复入口；关闭液态导航设置时恢复原 Toolbar 搜索菜单和 FAB。

## [S5] 搜索交互

点击搜索按钮后，该玻璃从当前位置连续展开为搜索输入胶囊，标题可适度淡出或让位，但页面内容不跳动。输入文字经过短防抖后写入现有 `currentSearch`，将 `currentPage` 重置为 1、清空分页状态并调用现有 `GetFriendRequestList` 搜索参数。

搜索框提供清除和收回操作。清空或退出搜索时恢复全量列表。过期请求返回时不得覆盖更新后的查询结果；搜索状态切换期间下拉刷新使用当前查询，分页继续携带当前查询。

## [S6] 生命周期与回退

交友液态顶栏只在 `useIosLiquidNavigation` 开启且当前 Tab 为交友宇宙时显示。切换 Tab、销毁 View 或关闭该设置时释放 Compose/controller 对 Activity、View 和回调的引用。

系统状态栏 inset 由 `HomeFragment` 统一传给当前液态顶栏。交友顶栏展开高度纳入顶部 backdrop 捕获高度，静止时继续沿用现有自适应捕获机制，不新增永久逐帧截图。

## [S7] 错误与空状态

首次加载、下拉刷新、分页错误继续使用现有 `LoaderFragment` 行为。搜索无结果显示现有空状态；搜索请求失败时保留当前查询文字并显示既有错误提示，不自动退回全量列表。

## [S8] 验收标准

- 浅色、深色和 Nord 主题下标题、玻璃、图标和列表内容可读。
- 大标题随慢拖和快速 fling 平滑收缩，回到顶部平滑展开。
- 卡片滚入顶栏后方时，搜索和发布按钮能折射真实卡片内容。
- 搜索防抖生效，快速输入不会让旧结果覆盖新结果；清除后恢复全量列表。
- 发布按钮进入既有发布页，原 FAB 在液态模式不重复出现。
- 下拉刷新、分页、空状态、详情和卡片菜单行为无回归。
- 关闭液态导航设置后恢复原 Toolbar 和 FAB。
- 完整 debug 构建成功，并在真机完成滚动、搜索、发布入口和主题验证。

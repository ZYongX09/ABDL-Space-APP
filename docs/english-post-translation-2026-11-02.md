# 英文适配与 AI 帖子翻译开发记录

## 交付范围

现有 App 的显示层英文适配和帖子翻译，不涉及 V4、不重新设计阅读器、不改变地图请求机制。用户随后要求先完成详情骨架、首页缓存和无缝动画，暂缓出测试包；仍不推 main、不发布正式 App、不安装覆盖用户已回退的设备。后续如构建测试包，只使用既有正式证书签名的 release 包，不生成 debug 包。

统一翻译后端与两站管理卡为配套开发成果，须另获授权发布并执行新迁移后才能在生产完整使用。测试包构建不等于后端已上线，不能用旧服务端冒充真实 AI 闭环。

## 应用语言

设置提供“跟随系统 / 简体中文 / English”。Android 13 及以上使用系统应用语言；Android 8–12 经现有 Application、原生 AppKit 和 Compose 宿主应用语言配置。界面/阅读语言与发帖语言分开。

自定义登录、NBW、地图显示、相册、赞助、扩列卡、小说、共享阅读器和编辑器使用英文默认资源，并保留中文限定资源。英文数量使用 K/M/B、语言适配的日期与复数；不翻用户正文、标题、管理员自填内容或机器 key。扩列卡游戏 ID、中文别名、平台字段、草稿及待提交操作输入不随显示语言改变。小说原有声明的持久值及摘要输入不换为英文。

切换语言之前同步检查草稿宿主。发帖/小说编辑忙碌、正在保存或不宜重建时可拒绝本次切换；正常重建保存草稿状态。小说大正文不塞入 Activity Bundle，仍使用现有本地文稿机制和 10 秒本地保存，不自动上传。系统自身语言重建依赖正常 SavedState/本地文稿，而非阻止系统设置。

## 翻译入口和显示

保留帖子“⋮”菜单、正文下方原有翻译说明/显示原文入口，新增正文上方模块。它们共用同一账号协调器、请求、用量与切换状态：

- 翻译前：灰色既有 App 图标与蓝色 `Translate post / 翻译帖子`。
- 翻译后：灰色图标、灰色 `Translated from Chinese / 翻译自中文` 与蓝色 `Show original / 显示原文`。
- 12sp 文案、16dp 图标和至少 48dp 点击目标；蓝灰颜色独立适配深浅模式，不随全局主题变成其他主色。
- 翻译在 CW/filter 隐藏链内；未展开不自动请求。真实 quote/reblog 内容身份与外层可见性分开，不用共享 parentID 更新错正文。
- 原文/译文切换不修改原始正文；媒体 ALT 和投票可选字段缺失时回退原值，不修改共享 Attachment。

目标语言来自当前有效 App 界面/阅读语言；en/en-US、zh/zh-CN 不因地区差异多翻。未知源语言不另发 AI 检测请求。客户端不能提供模型、prompt、正文或上游 URL。

## 协调与自动翻译

最多两个客户端在途任务、24 个排队项，只针对真实可见且展开的内容；不后台预翻整页。翻译模块离屏而正文仍可见时保持任务，只有 header/media/footer 等可见不触发自动翻译。

自动翻译默认关闭，须用户在账号设置主动启用，并由服务端确认当前有效赞助和管理策略许可。选择显示原文后，本次浏览不会被自动翻译立即覆盖。切账号、离页、内容编辑或语言变化使晚回包失效。

客户端成功译文缓存有数量和 60 秒时效上限，并带账号、目标和内容版本围栏；它不是服务端权限凭据。对结果不明的请求只查询任务状态，不盲目重新 POST。服务端全局成功缓存与客户端展示缓存不是同一层。

## 额度和安全

普通默认每日 5 条、英文阅读普通 10 条、有效赞助 100 条，不叠加，上海自然日重置。只计某个服务端内容版本/目标语言在全站首次成功生成的翻译；其他账号或入口读取已成功全局缓存不扣额、不调用 AI。服务端配额、占额、全局任务和权限验证是权威，不信客户端 UI 状态。

配套后端固定翻译 prompt，以 JSON 将帖子作为不可信数据；模型无工具或抓取能力。严格验证完整 JSON 字段、结束状态、实体占位、长度和时限，只输出安全转义的必要段落 HTML。统一供应商 HTTPS/DNS 预检拒绝本机/内网/保留地址、重定向；DNS 预检不是实际连接 IP pinning，也不能保证模型语义绝不受注入影响。

## 验证记录

资源审查：App 默认 3431 项，reader 21 项、editor 68 项；XML 解析、重复 key、格式占位错误均为零。App 默认资源仅保留中文语言自称和章节示例两处中文，不算漏翻。

独立库首轮：reader 40/40、novel-editor 27/27。App 生产与测试 Kotlin/Java 已编译通过；首次测试编译的 getApplication 泛型与列表夹具必需 URI 接口已定点修复，失败记录保留。原生专项运行85项时有11失败，修复真实字体配置、Dialog Handler与无效avatar等夹具后，复跑87项/85通过，仅剩小说真实1.8字体下editor正文零高与Featured标签溢出。通用英文10/10、语言管理跨API26/28/32/33的25/25、真实发帖草稿2/2、友卡英文10/10、翻译HTTP7/7+coordinator11/11+Fragment8/8+display8/8均实际通过，非已写即通过。之后两处小说响应式及截图观察发现的翻译源语言标签截断已定点修，最后NovelEnglishUiTest与PostTranslationDisplayTest同源12/12通过、前后28231文件指纹一致；真实320dp/1.8编辑区达到至少120dp及三行要求，InputConnection输入后生产保存操作写回SQLite且无上传，横滑分类保完整字号，320dp/1.6翻译来源标签完整显示源语言。不能把修复前截图或分次专项相加成最终全量。用户追加任务后暂缓APK构建/签名验收，不用旧APK冒充本轮包。

# 小说反馈修正与编辑体验优化

## 范围和发布边界

本轮针对小说重构后的用户反馈修正现有 Android App；不涉及 V4，不修改主站、移动站管理页面，也不介入并行的 AI provider 管理功能。阅读器继续使用 `reader-core`，不另造阅读器。私人书库只移除小说页中的旧入口，不删除本机或云端私人书籍。

交付目标为 `develop` 上的代码及使用既有正式证书的 release 测试 APK。当前轮次没有新的生产发布授权；不推进 `main`、不改正式下载、不部署 Worker、不执行生产迁移。0098/0099 已在上一轮生产执行，不得重放。本轮原作者字段存于已有不可变 metadata JSON，不需要新 DDL。

## 修正内容

- 转载资料新增原作者名，转载必填、最多 120 字；文字书封与作品署名使用原作者名。上传者账号、所有权、个人主页与关注关系仍指向真实上传账号。历史缺失姓名显示明确占位，不把上传者冒充为原作者。
- 新书、章节更新动态的主按钮统一进入作品详情，并使用“查看作品”“查看更新”的对应文案；普通手工附卡的“阅读作品”保持续读功能。
- 小说底栏复用首页真实背景采样链路；普通模式使用较紧凑的悬浮药丸。系统安全区只计算一次，内容留白随真实导航尺寸变化。
- 首页自定义更多与额外原生非 action 菜单重复的问题只移除重复入口，正常“关于”设置保留。小说页不再显示旧私人书架入口或页面标题下的装饰副文。
- 创作累计字数在大数时采用紧凑表示，并提供完整无障碍数值；章节数字列按实际字体测量，不允许三位数折行。
- 封面在选择后立即预览，保存在账号私有目录；JPG/PNG、EXIF 和 5 MB 限制在本机验证。上传复用既有 generic COS authorize/PUT/complete，保留 MIME，不再掉入 `/media` 的未知类型分支。
- 待上传封面仅保存在本地状态，失败保留图片与原有远端封面；新的本地封面尚未上传时不能提交审核。本地 URI、pending 标记不上行。
- 正文聚焦或键盘显示时收起无关说明与大块工具区域，保留必要保存反馈和编辑工具，正文原生输入控件保持同一实例，不因紧凑布局重建而丢失中文组合输入。
- 编辑器每 10 秒只在本机保存变化，不自动上传。封面上传也必须由用户明确触发；退出账号时固定会话身份取消在途请求，旧编辑器不能借同 ID 重新登录恢复授权。
- 阅读器由固定字符切页改为根据实际像素宽高、字体、字号、行距和缩放测量分页。页范围保留未修改原文及空白，不用 trim 跳过段落；重排按原文位置定位。
- 阅读器右上角功能按钮跟随标题/工具栏显隐，不在沉浸阅读时常驻；液态模式使用现有玻璃容器。工具区不盖住可读正文。

## 后端配套兼容

后端配套在隔离功能分支开发，`original_author` 仅是署名文本，不作为账号身份或权限输入。新转载稿缺名不得进入待审；历史不可变快照不回填、不修改，读取时补空字符串。旧幂等成功回执只在原请求确实省略字段且指纹精确匹配时只读重放，新写入仍严格校验。旧在途转载缺少原作者时必须取消并重新投稿，不能通过 finalize 偷换资料。

Android 对原创/AI 且署名为空时省略新增上行字段，保持与尚未部署配套的旧生产后端兼容。转载或非空署名必须传新字段，不能通过丢字段绕过要求。**新转载投稿需要配套后端上线后才具备完整生产能力；本轮开发交付不代表已上线。**

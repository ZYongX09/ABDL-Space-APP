## Android 8–12L 检查与修复

范围覆盖生产 main Java/Kotlin、release Manifest/resources、reader/novel/push 模块以及当前 appkit/Miuix 的关键调用边界：Insets/system bars、RenderEffect/RuntimeShader、软件与硬件 bitmap、媒体权限/存储、PhotoPicker、PendingIntent、服务通知、biometric/keystore、Parcelable、WebView、Java desugaring 与 native SDK 入口。

确认并修复一处实际可达缺陷：`LocationUtils.fetchAndResolve()` 使用只实现 onLocationChanged 的 framework LocationListener lambda，另三个回调直到 API30 才有默认方法；API26–29 在 provider/status 回调时可能 AbstractMethodError。现显式实现全部旧回调，保留位置更新处理。API26/27/28/29/30/31/32 的监听注册、状态/开关回调和无权限分支均覆盖。已正确实现取消/超时的 MapDeviceLocation 不改。

运行全 release Lint（含项目模块），保留完整 XML/HTML。API 调用检查未报 NewApi；3条 InlinedApi 已核对为 PhotoPicker 设备能力判断和媒体保存 API29 分支。项目仍有多语言缺失、旧规则、检测器限制及其他错误级诊断，**不是 Lint 全绿或全仓问题清零**，也没有通过禁用规则/升级最低系统掩盖。新推广图标使用 AppCompatImageView/app:tint，修掉本轮新增 tint 诊断；最终报告同时新增该布局第23行的 `MissingClass(AppCompatImageView)`。实际 APK DEX 包含该类，API26/28/32 真实布局构造和推广测试均通过，因此没有据该诊断删除兼容控件，但仍保留其错误级记录。最终报告合计1,333个Error、146个Fatal，不能将剩余诊断一概称为本轮前既有。

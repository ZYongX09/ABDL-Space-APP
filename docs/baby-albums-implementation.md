# 宝宝相册实现与验收边界

初始实现来自 Android 与后端的 `feat/baby-albums`。后端已完成生产 migration0071 与 main 自动部署；Android 与参考图上传页改版统一在 `fix/album-upload-ui-20261005`，2026-10-05 已按用户授权提交推送并通过 PR #5 交付 `main`（`32738ebd`），没有进入废弃develop。Android 未改正式版本号（仍 3.0.1/code32），调试构建使用 `.debug` 包名；不能把本地调试包当作已发布的新版 App。

## 用户入口

- 个人主页的“精选”替换为“相册”：自己的默认私有相册、公开/私有/共同相册；访问别人主页只显示当前有权限的相册。
- 首页液态玻璃发帖菜单新增“图片传相册”。
- 详情右下角加号进入上传，选择/创建相册、描述、高清/无损质量、可选秒级自定义时间。
- 公开相册上传自动发布相册更新帖。支持版本显示描述及紧凑卡片；网页和旧版保留固定提示文字。
- 共同相册由主人生成/轮换 7 天二维码邀请；登录后明确确认加入。已加入成员只读/点赞/评论，不能代替主人上传；支持成员撤权及主动退出。
- 图片继续使用原图片查看器：缩略图免费续签，高清/无损按服务端策略授权，单图点赞与底部评论区。评论/键盘出现时缩小图片 viewport，保持 FIT_CENTER。
- 主人长按详情照片可确认删除；非默认相册可在设置中确认删除。默认相册本身不可删除，照片可删，清理确认后恢复容量。

## 画质、额度与隐私

高清沿用普通发帖 `ResizedImageRequestBody`，仍有最长边 540 的预览。有效赞助者且本批每个源文件已知严格小于 20 MiB 时才可选择无损原图；不压缩源字节，同时上传高清与缩略图。无损只有相册主人可取。

容量由后端当前身份及实际赞助期限派生，普通/周/月/季/年/永久为 3/5/10/20/50/100 GiB。失去身份不会删除已有照片，超额时暂停新增。当前有效赞助者主人默认高清、下载高清免费；无损查看或下载仍按次消耗原图额度，同操作重试只扣一次。自动高清失败不会悄悄改为扣费授权。

相册独立私有 COS 对象、短效签名和 no-store 响应。原图/高清授权 URL 不放入持久媒体 Attachment 或磁盘图片缓存；上传暂存位于 no-backup 私有目录，稳定操作 UUID 与不变文件支持取消/恢复和未知发布结果重试。新帖/历史帖子通过后端安全复制到默认相册，无法证明所有权的链接不会伪造私有归属。

## 验证方式

新增 Robolectric 与离线 HTTP/图片处理用例覆盖默认时间 null、选择与编辑恢复、共享邀请 URL、源文件大小与 MIME、原图完全不压缩、私有 PUT 签名、不可变文件重试、未知 publish 恢复、照片删除确认、个人主页可见性桥接、短效预览续签、评论与键盘避让、赞助者容量及原生卡片。所有网络 fixture 拦截未知 host，不访问生产。

离线页面 PNG 来自真实 XML/View，不是生成的示意图；它们只验证本地框架渲染，不能证明真机字体/GPU、实际 COS 链路或双账号端到端可用。
